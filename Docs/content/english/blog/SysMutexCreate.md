# <center>`SysMutexCreate` - Function</center>

## Description
Create a platform-independent mutex object.

## Syntax
```c
SysMutex * SysMutexCreate(...);
```

## Behavior
**Success**: A valid SysMutex object

**Failure**: `NULL`

**Returns**: `SysMutex *`
