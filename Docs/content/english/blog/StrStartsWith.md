# <center>`StrStartsWith` - Function</center>

## Description
Check if string starts with another Str object.
s[in]     : Str to check.
prefix[in]: Str to check as prefix.

## Syntax
```c
bool StrStartsWith(...);
```

## Behavior
**Success**: Returns true if `s` starts with `prefix`.

**Failure**: Returns false.

**Returns**: `bool`
