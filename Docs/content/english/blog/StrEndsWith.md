# <center>`StrEndsWith` - Function</center>

## Description
Check if string ends with another Str object.
s[in]     : Str to check.
suffix[in]: Str to check as suffix.

## Syntax
```c
bool StrEndsWith(...);
```

## Behavior
**Success**: Returns true if `s` ends with `suffix`.

**Failure**: Returns false.

**Returns**: `bool`
